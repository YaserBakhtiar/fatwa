# مرجع فتاوای اسلامی

وبسایت مدرن و حرفه‌ای برای نشر فتاوای شرعی

## نحوه افزودن فتوی جدید

برای افزودن فتوی جدید، فایل `fatawa-data.js` را ویرایش کنید و یک آبجکت جدید به آرایه `fatawaData` اضافه کنید:

```javascript
{
    id: 13,  // شماره بعدی
    title: "عنوان فتوی",
    category: "دسته‌بندی",
    scholar: "نام مرجع",
    date: "۱۴۰۳/۰۳/۲۰",
    question: "متن سؤال",
    answer: "متن جواب"
}
